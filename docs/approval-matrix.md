# 批准矩陣

| 動作 | 可自動 | 必須批准 | 原因 |
|---|---:|---:|---|
| 名單入庫與計分 | 是 | 否 | 可逆且不對外承諾 |
| 產業包與目標配對 | 是 | 否 | 只能選擇靜態 registry，不執行客戶文字 |
| 產業包風險分級與範圍估算 | 是 | 否 | 估算不是收益或節省工時保證 |
| 受限範圍建立交付工作 | 否 | 不適用 | 先縮小為安全的讀取／草擬範圍並重新審查 |
| 寄送健檢結果 | 是 | 否 | 由表單本人觸發 |
| 對陌生名單寄信 | 否 | 是 | 反垃圾郵件與品牌風險 |
| 付款後建立專案 | 是 | 否 | 已驗簽且具冪等性 |
| 規格草稿 | 是 | 否 | 尚未寫程式或承諾交付 |
| 鎖定規格 | 否 | 是 | 決定範圍與成本 |
| AI 產生 patch | 是 | 規格先批准 | 只在隔離工作區 |
| 建立 preview | 是 | 否 | 不影響正式環境 |
| 已核准範本的對外訊息草稿 | 是 | 規格先批准 | 不可自動送出或建立新承諾 |
| 送出訊息、確定預約、公開發佈或寫入外部平台 | 否 | 是 | 品牌、合約、排程與誤擊風險 |
| 正式部署 | 否 | 是 | 影響客戶與營收 |
| 退款、折扣、刪除資料 | 否 | 是 | 財務或不可逆風險 |
| 使用真實客戶或員工個資 | 否 | 是 | 隱私與合約風險；優先使用聚合資料與 metadata |
| 金融、法律、醫療、住房、聘僱、安全或資格決策 | 否 | 否 | 屬產業包禁止用途，不得委任 AI |
