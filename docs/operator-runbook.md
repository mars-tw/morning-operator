# 每週操作手冊

## 每天 10 分鐘

1. 開啟 `/admin`。
2. 處理「需要你批准」；只批准看過的規格與部署證據。
3. 查看失敗工作；三次失敗會進人工處理。
4. 確認收入與付款事件沒有重複。

## 每週 60 分鐘

1. 執行 `pnpm backup`。
2. 執行 `pnpm restore-check` 驗證備份可回復。
3. 查看新名單、會談、成交與交付天數。
4. 只保留重複出現的需求，拒絕偏離固定商品的客製案。

## 事故

- 金流簽章錯誤：不建專案，保留雜湊與錯誤紀錄，人工查 provider 後台。
- 工作 dead-letter：不要無限重跑；先看最後錯誤與 artifact。
- 機密外洩：立即停 worker、輪替憑證、保存 audit log、判定通知義務。
- 資料庫異常：停止寫入，複製 `var/data`，從最近備份回復到新路徑後執行 integrity check。
